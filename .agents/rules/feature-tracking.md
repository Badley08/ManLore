# Rule: Feature Tracking & Markdown Summaries

Always generate or update a Markdown summary file (`walkthrough.md` or `SUMMARY.md`) after completing tasks or making code modifications.

## Mandatory Format for Features/Changes
In the generated Markdown file, list all requested and planned items with their explicit implementation status:

- `[X]` Feature / item added
- `[-]` Feature / item NOT added or omitted
- `[ ]` Feature / item pending

### Example:
- Nouveau mode [X]
- Nouveau style [-]
